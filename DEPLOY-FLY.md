# Деплой UKF Mail Bot на Fly.io

Цена: ~$2.19/мес (машина 256MB) + $0.15 (том 1 ГБ). Оплата по секундам,
без минимального контракта. Секреты — через `fly secrets set` (шифрованный vault,
не видны в git и в образе). Постоянные данные (seen.json, exports, chat_id, логи) —
на смонтированном томе /data.

## Что уже подготовлено в репозитории

- `Dockerfile` — образ Python 3.12, зависимости, DATA_DIR=/data.
- `fly.toml` — приложение `ukf-mail-bot`, регион fra (Франкфурт), том `ukf_data`.
  Публичных портов нет: бот только на исходящих соединениях (Telegram + POP3).
- `bot.py` / `seen_store.py` — читают секреты из переменных окружения, состояние
  пишут в DATA_DIR.
- `.dockerignore` — секреты (.env) и мусор не попадают в контекст сборки.

## Шаги

### 0. Аккаунт (5 минут)
Регистрация на https://fly.io — потребуется карта (для верификации, но списание
только по факту использования). Рекомендую включить 2FA в настройках аккаунта.

### 1. Установить flyctl (на своём компьютере)
Linux/macOS: `curl -L https://fly.io/install.sh | sh`
Windows: скачать с https://fly.io/docs/hands-on/install-flyctl/
Проверка: `fly version`

### 2. Войти
```
fly auth login
```

### 3. Создать том (1 ГБ, регион fra)
Том нужен ДО первого деплоя, иначе машина не стартует.
```
fly volumes create ukf_data --size 1 --region fra
```

### 4. Задать секреты (токен бота и данные почты)
```
fly secrets set TELEGRAM_BOT_TOKEN=123456:ABC... MAIL_USER=твой_номер MAIL_PASSWORD=твой_пароль TELEGRAM_ADMIN_ID=твой_telegram_user_id
```
- chat_id задавать НЕ нужно — бот сам определит его по команде /start
и запишет в файл на томе.
- TELEGRAM_ADMIN_ID — твой числовой Telegram user_id (узнать: написать
  боту @userinfobot). Бот отвечает ТОЛЬКО тебе, остальные игнорируются.

### 5. Задеплоить
Из папки проекта (на твоём компьютере):
```
fly deploy
```
Первая сборка идёт на стороне Fly (remote builder), локальный Docker не нужен.
Fly сам подставит переменные окружения из secrets и смонтирует том.

### 6. Запустить бота
Отправь боту в Telegram команду /start. Он ответит приветствием, определит
твой chat_id и запишет его на том. После этого:
- новые письма будут приходить каждые 10 минут (только если письма есть —
  сообщений «почта пустая» нет, чат не засоряется);
- раз в сутки придёт heartbeat «🤖 Бот жив» со статусом почты;
- команда /check — проверить почту сейчас.

## Обслуживание

```
fly logs              # живые логи
fly status            # состояние машин
fly ssh console       # зайти внутрь машины
fly deploy            # задеплоить новый код после правок
fly secrets list      # список секретов (значения не показываются)
fly volumes list      # список томов
```

## Если память не хватит (команда /getmail выгружает до 200 писем)

Машина 256MB обычно справляется, но при очень больших письмах может получить
OOM-kill. Тогда увеличь память — $3.69/мес за 512MB:
```
fly scale memory 512
```

## Что будет после перезапуска машины

- seen.json — на томе, не потеряется, дублей писем не будет.
- chat_id — на томе (/data/chat_id), бот продолжит присылать уведомления.
- exports (файлы выгрузки /getmail) — на томе.
- Логи — на томе (/data/logs/bot.log) + в `fly logs`.
