# UKF Mail Bot 📬

Телеграм-бот для университетской почты UKF (`vadym.ukrainskyi@student.ukf.sk`).
Следит за Входящими, присылает новые письма в Telegram и умеет выгрузить
всю почту в один TXT-файл.

## Что умеет

| Команда | Что делает |
|---|---|
| `/start` | приветствие + сохраняет твой chat_id для уведомлений |
| `/getmail` | читает «Входящие» и присылает один TXT-файл со всеми письмами (от кого, тема, дата, текст) |
| `/check` | проверяет почту прямо сейчас, не дожидаясь расписания |
| `/status` | проверяет связь с почтой и показывает настройки |

Автоматически, каждые **5 часов**, бот проверяет Входящие:
- есть новые письма → присылает их тебе;
- писем нет → пишет «Новых писем пока нет».

Все события пишутся в `logs/bot.log`.

## Подключение к почте

Бот работает через **POP3** (порт 995) — сервер `studentmail.ukf.sk`
(Dovecot). Важно:

- IMAP на сервере UKF **отключён** — доступны только «Входящие».
  Спам и Корзину бот читать не может (ограничение протокола).
- Логин — **номер студенческого билета** (именно цифры, НЕ email-адрес).
  Пароль — тот же, что для webmail.
- Office 365-эндпоинт (`outlook.office365.com`) вход по паролю
  не принимает (`Basic authentication is disabled`) — это нормально,
  бот им и не пользуется.

## Как запустить у себя (VS Code)

1. Открой папку `/home/vadim/ukf-mail-bot` в VS Code.
2. Файл `.env` уже заполнен: токен бота, номер студенческого билета
   (`MAIL_USER`) и пароль от webmail. Проверь, что пароль верный,
   и при необходимости поправь.
3. Создай и активируй виртуальное окружение (один раз):

```bash
cd /home/vadim/ukf-mail-bot
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
```

4. Запусти бота:

```bash
./venv/bin/python bot.py
```

5. Напиши боту в Telegram `/start` — chat_id сохранится автоматически,
   и начнут приходить уведомления.

> Важно: в VS Code выбери интерпретатор из этого проекта — нажми
> `Ctrl+Shift+P` → «Python: Select Interpreter» → выбери
> `./ukf-mail-bot/venv/bin/python`. Иначе VS Code возьмёт системный
> питон, где пакеты не установлены, и получишь `ModuleNotFoundError`.

## Как задеплоить на PythonAnywhere

1. Зарегистрируйся на https://www.pythonanywhere.com
   (бесплатного аккаунта достаточно).
2. **Files** → загрузи все файлы проекта (`bot.py`, `mail_client.py`,
   `seen_store.py`, `requirements.txt`, `.env`) в папку
   `/home/<твой_логин>/ukf-mail-bot/`.
3. Открой **Consoles** → **Bash** и выполни:

```bash
cd ~/ukf-mail-bot
pip install --user -r requirements.txt
```

4. Проверь, что .env на месте с паролем (`cat .env`).
5. Перейди в **Tasks** (вкладка сверху) и создай задачу:

```
Command:  python3 /home/<твой_логин>/ukf-mail-bot/bot.py
```

   На бесплатном тарифе задача может работать ограниченное время в сутки —
   для бота, который просто иногда проверяет почту, этого хватает.
   Альтернатива: **Always-on task** (доступен на платном тарифе, от $5/мес) —
   тогда бот будет работать круглосуточно.

6. Нажми **Run** и напиши боту `/start`.

### Важно про PythonAnywhere

- Бесплатный аккаунт позволяет исходящие соединения только на
  whitelisted-сайты (Telegram в whitelist входит, IMAP-порты — **нет**).
  Проверено: `outlook.office365.com:143` из некоторых сетей блокируется.
  Если почта не подключается на PythonAnywhere — понадобится платный
  аккаунт (у него unrestricted internet access).
- При первом запуске на сервере напиши боту `/start`, чтобы chat_id
  прописался в .env, иначе уведомления некуда слать.

## Файлы

```
ukf-mail-bot/
├── bot.py           — телеграм-бот и команды
├── mail_client.py   — IMAP-подключение и чтение писем
├── seen_store.py    — помнит, какие письма уже присылались
├── .env             — секреты (токен, логин, пароль) — НЕ коммить!
├── requirements.txt — зависимости
├── seen.json        — создаётся сам, история просмотренных писем
├── logs/bot.log     — лог работы
└── exports/         — сюда падают сгенерированные TXT-выгрузки
```

## Безопасность

- `.env` с паролем от почты **не выкладывай** в публичные репозитории.
- Токен бота ты уже передал в чат — после деплоя стоит сделать
  `/revoke` в @BotFather и вписать новый токен в .env, чтобы никто
  посторонний не управлял ботом.
